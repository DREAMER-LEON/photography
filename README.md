## 关于本站

单页静态站点，无构建步骤。`index.html` 为唯一页面，图片与音频均以相对路径引用。

- 点击任意照片可打开全屏灯箱：`←` `→` 切换，`Esc` 关闭，触屏可左右滑动
- 左下角圆形按钮控制背景音乐（受浏览器策略限制，需首次交互后才会开始播放）
- 页面滚动时照片渐显；已适配 `prefers-reduced-motion`
